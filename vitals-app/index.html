Clinical Study Notes

Session data is recorded locally in your browser memory every 3 seconds. For research or final year project reporting, use the Export Session CSV button to generate structured datasets for Bland-Altman agreement plots, RMSE error, and statistical verification against reference pulse oximeters.

Bluetooth Low Energy (BLE) DIRECT WIRELESS

Connects directly to the watch GATT server (Vitals-Watch). Transmits real-time BPM, SpO₂, temperature, and filtered 250 Hz ECG telemetry without needing a shared Wi-Fi router.

Local Wi-Fi Network / Hotspot TCP / IP

Connect over your local LAN or the watch's built-in access point hotspot (Vitals-Watch / password vitals123).
